# altered-carbon v1.0.0

This release expands the bootstrap script beyond core workstation setup into AI-adjacent developer tooling, while also making non-admin runs more capable.

## Highlights

- Added GitHub Copilot CLI installation and upgrade support through the `github/gh-copilot` GitHub CLI extension.
- Added Microsoft Work IQ CLI installation and upgrade support through the npm package `@microsoft/workiq`.
- Added Node.js LTS winget fallback so non-admin runs can still provision npm-dependent tooling.
- Expanded the managed VS Code extension set with GitHub Copilot Chat, GitHub Copilot for Azure, and AI Toolkit for Visual Studio Code.
- Added a post-install verification summary so the script reports what is actually available on the machine after setup.

## Why This Release Matters

Previous versions focused on core workstation setup. This release closes a practical gap: AI tooling often depends on npm, GitHub CLI extensions, and editor integrations that were not previously managed as part of first-run setup.

With `v1.0.0`, a fresh machine can now get much closer to a ready-to-work state without requiring admin elevation for every useful developer tool.

## Included Changes

### Installer updates

- Added GitHub Copilot CLI management in the main setup script.
- Added Microsoft Work IQ CLI management in the main setup script.
- Added `OpenJS.NodeJS.LTS` as a winget fallback when Chocolatey is unavailable or not desired.

### Editor tooling updates

- Added `github.copilot-chat`.
- Added `ms-azuretools.vscode-azure-github-copilot`.
- Added `ms-windows-ai-studio.windows-ai-studio`.

### Verification and reporting

- Added a final summary block that reports installed and missing status for the key CLIs.
- Added extension status reporting for both VS Code and VS Code Insiders.

### Documentation

- Updated the README to describe the new tools and fallback behavior.
- Added a project changelog to make future tagged releases easier to track.
